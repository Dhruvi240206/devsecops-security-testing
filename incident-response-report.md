# Experiment 10: DevSecOps Culture and Collaboration

## 1. Objective
To promote collaboration between Development, Operations, and Security teams through a collaborative incident response exercise and identify areas for improved communication and cooperation.

## 2. Tools Used
- GitHub
- GitHub Issues
- Markdown documentation

## 3. Incident Scenario
A simulated security incident involving potential unauthorized access to a web application was considered. The teams collaborated to investigate, contain, resolve, and prevent the incident.

## 4. Teams and Responsibilities

### Development Team
- Investigated the potential vulnerability.
- Reviewed input validation and access control.
- Prepared security improvements.
- Tested the updated application.

### Operations Team
- Monitored application activity.
- Reviewed system logs.
- Checked application availability.
- Prepared incident containment measures.

### Security Team
- Assessed the security risk.
- Reviewed potential vulnerabilities.
- Recommended security improvements.
- Verified the implemented fixes.

## 5. Incident Response Process

1. Detection: A potential security vulnerability was reported.
2. Communication: All three teams were informed through a GitHub Issue.
3. Investigation: Teams reviewed the potential security weakness.
4. Containment: Operations reviewed monitoring and containment measures.
5. Resolution: Development prepared security improvements.
6. Verification: Security reviewed the proposed fixes.
7. Closure: The teams documented the simulated resolution.

## 6. Areas for Improved Communication and Cooperation

- Establish a common communication channel for incident reporting.
- Clearly define responsibilities for each team.
- Share security findings with developers at an early stage.
- Conduct regular cross-team security meetings.
- Maintain proper incident documentation.
- Encourage continuous feedback between teams.
- Establish clear incident escalation procedures.

## 7. Outcome
The collaborative incident response exercise demonstrated how Development, Operations, and Security teams can coordinate their responsibilities to manage a security incident.

The exercise highlighted the importance of communication, shared responsibility, transparency, and continuous security monitoring.

## 8. Conclusion
DevSecOps culture encourages collaboration between development, operations, and security teams throughout the software development lifecycle. This experiment demonstrated how effective communication and cooperation can improve incident response and strengthen application security.
